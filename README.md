# MEOW WORLD — FINAL BIRTHDAY PROJECT

## Run
1. Open this folder in VS Code.
2. Open PowerShell in this folder.
3. Run: `python app.py`
4. Use the URL opened by `app.py`.

Python's built-in `http.server` is used for the local server.

All slideshow cards are strictly 1:1 square.

The first transition is a rainbow arc + four hanging square photos.
Later transitions use a left-to-right plane + five square contrail cards.
Transitions are about 1.9 seconds.

Fireworks are canvas skyshots: one projectile launches at a time, bursts into a multi-colour particle flower, and new shells keep launching for about 5 seconds.

Candles are individually clickable/tappable. The cake page has no normal Next button; the final candle reveals the letter, and only then can the final page open.

The project is intentionally asset-ready: replace the empty JPG/MP3/MP4 placeholders with your own media. Do not rename them.
